# jGrav
naive small gravity simulation using the awt renderer from [jboids](https://github.com/iiandromedaa/jboids)<br>
made for a physics class<br>
make orbits and etc!!

### controls
mouse1 click to create a body<br>
drag while holding down mouse1 to give your body an initial velocity<br>
mouse2 click to hide/unhide body creation widget as well as labels for existing bodies<br>
p to pause<br>
space to clear simulation<br>
