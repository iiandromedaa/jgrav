# jGrav
naive small gravity simulation using the awt renderer from [jboids](https://github.com/iiandromedaa/jboids)<br>
made for a physics class<br>
make orbits and etc!!

### controls
mouse1 click to create a body (make sure the widget is active first)<br>
drag while holding down mouse1 to give your body an initial velocity<br>
mouse2 click to hide/unhide body creation widget as well as labels for existing bodies<br>
scroll with the body widget open to change the selected mass of body to create<br>
middle mouse to pan around<br>
p to pause<br>
space to clear simulation<br>
i to accelerate time<br>
k to decelerate time<br>
n to change sign of selected body mass (this is not physically possible so expect nonsense because of negatives)<br>
